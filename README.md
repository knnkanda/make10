# Make 10 パズル (Make 10 Puzzle)

数字を繋げて「10」を作る、新感覚の落ち物パズルゲームです！
未就学児〜小学生の「数の合成（10の補数）」の直感的な理解を助けるために開発されましたが、大人の脳トレとしても楽しめる爽快な連鎖パズルになっています。

## ✨ 特徴 (Features)
* **直感的なルール**: テトリスやぷよぷよのように、上から降ってくる数字ブロックを積み上げます。
* **足して10で消滅**: 縦・横に繋がったブロックの合計が「ちょうど10」になると、派手なエフェクトと共にブロックが消えます（2個でも3個以上でもOK！）。
* **爽快な連鎖（チェイン）**: ブロックが消えて宙に浮いたブロックは下に落ちます。そこで新たに「10」ができれば大連鎖が発生！
* **戦略性**: 「つぎ」だけでなく「つぎのつぎ」まで見えるため、先読みしてブロックを配置するプログラミング的思考が育ちます。
* **ブラウザで即プレイ**: HTMLファイル1枚で動くため、面倒なインストールは一切不要です。

## 🕹️ 遊び方・操作方法 (How to Play)
* **[ ← ] / [ → ]キー**: ブロックを左右に移動させます。
* **[ ↓ ]キー**: ブロックを早く落とします。

## 📖 ルール詳細 (Rules)
1. 上から1〜9までの数字が書かれたブロックが落ちてきます。
2. 隣り合う（縦・横）ブロックの数字を足して、合計が「10」になる組み合わせを作ります。
   * 例: 「2」と「8」
   * 例: 「1」と「4」と「5」
   * 例: 「2」と「1」と「6」と「1」
3. 合計10になるとブロックが弾けて消え、スコアが加算されます。
4. 一気にたくさんのブロックを使って10を作ったり、連鎖させたりすると高得点になります。
5. 一番上の行までブロックが積み上がってしまうとゲームオーバーです。

## 🚀 実行・導入方法 (Getting Started)
このリポジトリのHTMLファイルをブラウザで開くだけで、ローカル環境ですぐに遊べます。

1. リポジトリから `make10.html` (または `index.html`) をダウンロードします。
2. Google ChromeやSafariなどのWebブラウザにファイルをドラッグ＆ドロップして開きます。
3. すぐにゲームが始まります！
